Prototype 1

This prototype features simple event sliders without any colours and simple text to describe them. I wanted to see whether basic inputs and less overstimulating options might be favoured amongst users.


Prototype 2

Link

This prototype features sliders that are coloured and also a black background. The black background was chosen to make the colours pop and stand out more and the colours were chosen to represent the moods and give users a good way to remember each of the sliders and their impacts. This could be taken further in future by possibly impacting the colour of the event.


Prototype 3

Link

This prototype keeps the same background as the first but introduces the colours too. It also switches up some of the labels to see if they fit better with the event system along with their corresponding colours. The numbering under the sliders and the individual slider names have also been removed to limit clutter and are all under the heading "Attributes". This is to see if the sliders and colours feel better when there is no monetary value attached to them.


Prototype 4

Link

This prototype adds the "Play calendar" feature which plays notes corresponding to the events that have been created. The main interaction here is the user creating the events and it replays them in chronological order. Depending on the duration also of the event, the notes play for shorter or longer. This allows for most of the creative process being focused on the calendar aspect but may lack interactivity.


Prototype 5

Link

This prototype changes the "Play Calendar" button to open a new screen that has squares in place of the events in the calendar. These squares play the same notes as the previous prototype but are now controlled by the user when they click on them. The squares are laid out in the shape of the calendar month the user is looking at and can be played like an instrument.


Prototype 6

Link

This prototype keeps the same layout as the previous but adds a hover effect cursor to the instrument page. The events are now circular and play their note when the user hovers over them. Multiple notes can play at the same time and create for interesting sounds. This way the user can target a specific part of the calendar and get a feel for it. The notes also dont have a duration anymore but the size of the circle is now determined by how long the event is.
